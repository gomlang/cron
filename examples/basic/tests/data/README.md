# Independent reference vectors

`ordinary.tsv.gz`: 640 cases (160 schedules × four starting instants), generated
by `reference/main.go` using github.com/robfig/cron/v3 v3.0.1, pinned in go.mod and
go.sum. Every row contains expression, exclusive after, inclusive until,
matches(after), and earliest occurrence or `none`. Five-year intervals align
with the reference's built-in horizon. The common grammar excludes our Sunday=7
extension, which has explicit hand-expected tests. Unlike robfig, this library
rejects empty list members, signs, `?`, descriptors and embedded timezone syntax.

`zones.tsv.gz`: 900 cases (ten transition/historical windows × five schedules ×
six starting instants × three fold policies), generated by `reference/zones.py`.
Python zoneinfo loads the exact shipped TZif files and enumerates **UTC** instants
in increasing order. It filters local wall minute/hour values, computes ambiguity
by independent fold round trips, and selects the first UTC result. It does not
use this library's wall-date search algorithm or its ±93599-second proof bound.
Historical second-offset scenarios enumerate by second; others by UTC minute.

Coverage includes New York's one-hour gap/fold, Lord Howe's half-hour gap/fold,
Apia's skipped date, Dublin's transitions, Kathmandu's 1986 quarter-hour gap and
1900 second offset, and New York's 1880 second offset. Rows retain `none` results.
Returned instants are also checked through public `matches` with the same policy.

Regenerate from `reference/`: `go run .` and `python3 zones.py`. Outputs are gzip
streams without timestamps; native tests need neither generator nor network.
Reference implementations are test tools only and are not runtime dependencies.
